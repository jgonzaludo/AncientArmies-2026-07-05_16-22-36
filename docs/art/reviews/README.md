# Art Reviews

Review notes for character-art milestones live here, one file per review:

```
YYYY-MM-DD_<subject>.md      e.g. 2026-07-20_base_body_blockout.md
```

Each review should record: what was reviewed (Blender file / screenshot /
Unity capture), verdicts against the specs in `../specifications/`, requested
changes, and explicit approvals. Approval to proceed past a pipeline stage
(base body → clothing → armor → …) should be captured here.
