# Art direction

The active visual target for Ancient Armies. Every production asset is judged
against this document.

## The look

**Stylized mobile tactical RTS with a premium board-game miniature
appearance.** Think a beautifully painted tabletop army viewed from above —
not photoreal history, and not cartoon caricature.

Core qualities:

- **Chunky and rounded.** Solid, weighty silhouettes.
- **Soft-beveled surfaces.** No razor edges; forms catch light broadly.
- **Low visual noise.** Large clean shapes beat busy detail.
- **Readable at fixed isometric gameplay distance.** This is the acceptance
  test for every asset.

## Proportions

Adult but deliberately stocky — soldiers read as grown men, not children:

- Approximately **2.6 heads tall**
- **Large rounded head** — the primary read at gameplay distance
- **Thick limbs** — no thin, fragile shapes that disappear when zoomed out

## Silhouette and equipment

- Equipment must be **historically distinguishable**. A viewer should be able
  to tell a legionary from an archer from a command role by silhouette alone.
- **Basic Roman legionaries have no crest.** Crests are reserved for command
  roles, so a crest is a rank signal, not decoration.
- **Shield is held in the left hand.**
- **Primary weapon is held in the right hand.**

## Built for formations

Every asset is designed to appear **many times at once**, in ranks, at
distance:

- Silhouettes must stay distinct when 80 of them stand shoulder to shoulder.
- Detail that only reads in a close-up is wasted work.
- **Tiny details that cannot be read during gameplay must not drive
  production.** If it does not survive the gameplay camera, it does not get
  authored.

## Modularity

Build from **modular base bodies, clothes, armor, helmets, and equipment**, so
new unit types are assembled from a shared kit rather than sculpted from
scratch each time.

## Faction color

**Faction colors are swappable in Unity.** Author neutral, and drive team
identity through material/color swaps at runtime rather than baking a faction
into a mesh or texture. Blue and Red must be produced from the same source
asset.
